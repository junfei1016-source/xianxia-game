# 法言天地 · AI 开放修仙游戏

一个**生成式**修仙文字游戏：每局开局由大模型现场生成独一无二的世界与角色，剧情由玩家与 AI 共同演绎。开发者只定义"天道规则"与"通关条件"，不预设剧情内容。

## 核心设计

- **AI 主持人（GM）**：接入任意 OpenAI 兼容接口（DeepSeek / OpenAI / 通义 / 智谱 / Kimi 等）。采用"两段式"：GM 先写纯叙事（非 JSON，稳定），再由专职状态提取器从叙事中提取数值与新内容（JSON）。
- **每局皆不同**：世界种子（出身 / 天下大势 / 起始地 / 引路人 / 开局钩子）由 AI 现场生成，支持「完全随机」或「出身问卷」两种开局。
- **属性系统**：AI 有权修改玩家所有数值属性（气血/寿元/灵石/正邪/声望/修为等），但必须基于对玩家行为的评估——合理行动才有相应收益，空口索要会被剧情拒绝或附带代价，不会要什么给什么。
- **多难度**：简单/普通/困难/炼狱——AI 判罚更严 + 伤害乘数 + 高危行为死亡掷骰，死亡由机制保证，不再是 AI 心情。
- **任务系统**：主线「飞升成仙」+ AI 生成支线（含任务目标/叙事化期限/奖励，AI 判定是否值得设为任务），右侧「任务」页统一查看。
- **节奏与回合**：开局可选快/慢节奏（影响修为成长速度）+ 可选通关回合上限，回合数实时统计。
- **时间与寿元**：游戏内年/月日期随回合推进，寿元随之消耗，闭关/赶路可跨月年（由叙事提取），寿元耗尽则坐化。
- **瓶颈突破**：修为圆满后进入瓶颈，单纯苦修无法突破，需机缘（丹药/传承/顿悟/磨砺）方可破境，形成"苦修→寻机缘→突破"节奏。
- **规则化通关**：固定主目标「飞升成仙」，另有身死道消、堕入魔道等结局；通关由规则引擎判定，AI 只负责"演"，不拍板。
- **隐藏成就**：境界 / 财富 / 声望 / 正邪 / 开宗立派 / 誓愿达成等，规则判定、自动解锁。
- **誓愿目标系统**：玩家可立下复仇、寻亲、争霸等个人目标，由 GM 记录、规则引擎判定达成。
- **长期记忆**：久远回合自动压缩成「剧情记忆」，玩很久也不失忆、不自相矛盾。
- **存档 / 读档**：每回合自动存档 + 3 个手动档位 + 「继续上次游戏」。

## 快速开始

1. 确认本机已装 Node.js（≥18，推荐 20+，本机已测 Node 24）。
2. 在本目录启动：

```bash
node server.mjs
```

3. 浏览器打开 <http://localhost:3000>。
4. 左侧填写 **Base URL / API Key / Model**（默认 DeepSeek `https://api.deepseek.com` + `deepseek-v4-flash`，也可换成 `deepseek-v4-pro` / `deepseek-chat` 等）。
5. 点「开始新游戏」即可游玩。

> API Key 只存在浏览器 localStorage，后端仅做转发，不落盘。

## 测试

```bash
node test.mjs   # 验证规则引擎与解析容错（32 项断言）
```

真实大模型联调（需先启动 `node server.mjs`，Key 通过环境变量传入、不写进文件）：

```bash
$env:DSH_KEY='sk-...'; node test_live.mjs
$env:DSH_KEY='sk-...'; $env:DSH_MODEL='deepseek-v4-flash'; node test_money.mjs
$env:DSH_KEY='sk-...'; $env:DSH_MODEL='deepseek-v4-flash'; node test_quest.mjs   # 难度/支线任务/风险
```

> 稳健性：叙事采用非 JSON 模式（稳定），状态采用短提示词 JSON 提取（含空响应退避重试 + 弯引号解析容错），保证对话不卡死、属性与通关状态不丢失。
