========================================================
  法言天地 · AI 开放修仙游戏 —— 启动说明
========================================================

这是一个「生成式修仙文字游戏」：世界、人物、剧情每局由 AI 现场生成，
你只需自由行动（修炼 / 寻宝 / 拜师 / 经商 / 复仇…），目标是渡劫飞升、位列仙班。

--------------------------------------------------------
一、直接双击 exe 玩（推荐，无需安装任何东西）
--------------------------------------------------------
1. 双击本文件夹里的  法言天地.exe
   - 会弹出一个黑色命令行窗口（服务器日志，不要关闭它）；
   - 浏览器会自动打开游戏页面 http://localhost:3000
   - 若浏览器没自动打开，手动访问 http://localhost:3000 即可。

2. 第一次运行 Windows 可能提示「Windows 已保护你的电脑」：
   → 点「更多信息」→「仍要运行」。（因为 exe 未做商业签名，属正常现象）

3. 玩完想退出：关掉浏览器页面 + 关掉黑色命令行窗口即可。

4. 系统要求：Windows 10 / 11（64 位）。整个游戏只有这一个 exe 文件，
   发给别人直接双击就能玩，对方不需要安装 Node.js。

--------------------------------------------------------
二、第一次进游戏（两种启动方式都要看）
--------------------------------------------------------
1. 页面左侧「模型配置」里：
   - Base URL 保持默认 https://api.deepseek.com
   - API Key 粘贴你自己的 DeepSeek 密钥（sk-...）
   - Model 默认 deepseek-v4-flash（快）即可
   DeepSeek Key 获取：https://platform.deepseek.com →「API Keys」创建。
2. 点「进入游戏」→「开始新游戏」。
3. 在底部输入框打字行动，回车即玩。

--------------------------------------------------------
三、开发者方式启动（改代码时用）
--------------------------------------------------------
1. 需要 Node.js（版本 18 及以上，推荐 20+）：https://nodejs.org
2. 在本目录打开命令行，输入：
       node server.mjs
   看到「法言天地 AI 游戏已启动」后访问 http://localhost:3000

--------------------------------------------------------
四、改完代码后重新打包 exe
--------------------------------------------------------
本目录提供了打包脚本 build-exe.ps1（自动完成全部步骤）：
1. 在 PowerShell 里进入本目录，运行：
       Set-ExecutionPolicy -Scope Process Bypass
       .\build-exe.ps1
   （若系统策略拦截，先在管理员 PowerShell 里执行一次
      Set-ExecutionPolicy RemoteSigned）
2. 脚本会重新生成 sea-prep.blob → 复制 node.exe → 注入 PE 资源
   → 翻转哨兵熔丝，最后产出新的 法言天地.exe。
   注意：打包用的 node.exe 版本必须与生成 blob 的版本一致。

--------------------------------------------------------
五、常见问题
--------------------------------------------------------
Q1：提示「缺少 baseUrl / apiKey」或 AI 不回话？
   → 检查 API Key 是否填对、账户是否有余额、网络能否访问 DeepSeek。

Q2：3000 端口被占用？
   → exe 版：关掉旧的黑色窗口再双击。
   → 开发版：换个端口，set PORT=4000 再 node server.mjs，
     然后访问 http://localhost:4000

Q3：防火墙弹窗？
   → 点「允许访问」即可（本机运行一般不会弹）。

Q4：想改难度 / 节奏 / 修为增益？
   → 都在左侧「新游戏」面板里选，选完再点「开始新游戏」。

Q5：API Key 安全吗？
   → Key 只存在你自己浏览器里，服务器只做转发、不保存。
