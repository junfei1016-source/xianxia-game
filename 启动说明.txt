========================================================
  法言天地 · AI 开放修仙游戏 —— 启动说明（v1.3.2）
========================================================

这是一个「生成式修仙文字游戏」：人物、剧情、机缘每局由 AI 现场生成，
世界骨架（区域、势力、路程、物价）由规则表兜底。你自由行动
（修炼 / 寻宝 / 拜师 / 经商 / 复仇…），目标是渡劫飞升。

--------------------------------------------------------
一、双击桌面「法言天地」快捷方式（推荐）
--------------------------------------------------------
1. 双击桌面上的  法言天地  图标。
   - 它调用本目录的 启动游戏.cmd：先起本机服务，再自动打开浏览器
     http://localhost:3000
   - 会有一个最小化的黑色窗口，标题「Xianxia server…」——
     关掉它服务就停，别关早了。
2. 服务已经在跑时，再双击只会打开浏览器，不会重复启动。
3. 玩完：关浏览器页面 + 关掉那个黑色窗口。

※ 桌面原来的 法言天地.exe 是 2026-08 打包的 v1.1.x 旧版，
   已移到  publish\法言天地-v1.1.3.exe  备份，请不要再双击它
   （旧版没有世界骨架、人物性格库和势力底细）。

--------------------------------------------------------
二、手动启动（不想用快捷方式 / 快捷方式坏了）
--------------------------------------------------------
在本目录打开命令行，任选其一：

   启动游戏.cmd

或直接用本机自带的 Node（本机没装系统 Node，走 DSH 这份）：

   & "C:\Users\fym10\.dsh\dsh-runtimes\dsh-primary-runtime\dependencies\node\bin\node.exe" server.mjs

看到「法言天地 AI 游戏已启动」后访问 http://localhost:3000

端口被占用：set PORT=3005 之后再启动，访问 http://localhost:3005

--------------------------------------------------------
三、第一次进游戏
--------------------------------------------------------
1. 页面左侧「模型配置」：
   - Base URL 保持默认 https://api.deepseek.com
   - API Key 粘贴自己的 DeepSeek 密钥（sk-...）
   - Model 默认 deepseek-v4-flash（快）即可
2. 点「进入游戏」→「开始新游戏」。
3. 底部输入框打字行动，回车即玩。

免 Key 只看界面（固定假响应，不花钱）：

   & "C:\Users\fym10\.dsh\dsh-runtimes\dsh-primary-runtime\dependencies\node\bin\node.exe" scripts\review-state-guards.mjs

然后打开 http://127.0.0.1:3103/__review ，点「加载快节奏」→ 进游戏后点
「继续上次游戏」，输入 混合校验 / 终态改写 / 数值溢出 看拦截效果。

--------------------------------------------------------
四、改完代码后重新打包 exe（可选）
--------------------------------------------------------
1. 在 PowerShell 里进入本目录：
       Set-ExecutionPolicy -Scope Process Bypass
       .\build-exe.ps1
2. 脚本会生成 sea-prep.blob → 复制 node.exe → 注入资源 → 产出新 exe。
   注意：打包用的 node.exe 版本必须与生成 blob 的版本一致。
   本轮（v1.3.2）没有重新打包，源码运行版才是最新的。

--------------------------------------------------------
五、常见问题
--------------------------------------------------------
Q1：双击快捷方式，浏览器打开了但页面打不开？
   → 看那个黑色窗口是否报错；多半是 3000 端口被占，按第二节换端口。

Q2：提示「缺少 baseUrl / apiKey」或 AI 不回话？
   → 检查 Key、余额、网络能否访问 DeepSeek。

Q3：想让 AI 别乱编距离和物价？
   → 已经由世界表兜底：赶路按天数结算、物价按区域系数，切片里写着。

Q4：想查白鹿观的底细？
   → 在游戏里输入「打听白鹿观的底细」这类调查动作，才能拿到线索；
     查到实证前，界面不会提前标「表里不一」。

Q5：API Key 安全吗？
   → Key 只存在你自己的浏览器里，服务器只做转发、不保存。
