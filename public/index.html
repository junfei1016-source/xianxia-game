世道底子（调试）
    游戏说明
    目标与结局

    修炼至渡劫期、渡过天劫，飞升成仙即通关。结局：飞升成仙 / 身死道消 / 堕入魔道 / 寿元耗尽 / 时不我待 / 一统江湖。

    怎么玩

    在输入框自由行动（修炼、寻宝、拜师、经商、复仇、索要……），AI 主持实时演绎后果；剧情、人物、世界每局现场生成，绝无雷同。属性：气血、寿元、灵石、正邪、声望、修为。

    修炼与突破

    闭关：任何阶段都正常涨修为；但连续闭关收益递减（100%→85%→70%→60%），出游/探索后恢复。

    小境界（初期→中期→后期）：修为圆满即可破；有丹药/天材地宝辅助可更快、甚至连破多个小境界。

    大境界（如炼气后期→筑基初期）：修为圆满后还需机缘（丹药/天材地宝/传承/顿悟）才能跨过。

    化神→飞升：还需道心（正邪/声望达标）+ 渡劫准备（护法/法宝）。

    走火入魔：强行突破失败可能走火入魔，修炼收益下降，需丹药或静养化解。

    渡劫（关键）

    修为圆满后，状态面板出现「突破大境界 / 渡劫飞升」按钮。点击后显示真实成功率（装备稀有度、词条、道侣护法、道心都会加成），可「确认突破」或「再准备准备」。

    失败后果：修为大降；渡劫失败还有概率身死道消——准备越充分越安全，裸渡致死约 13%~48%（随难度：简单 13% / 普通 25% / 困难 36% / 炼狱 48%）；永远保留 5% 搏一搏的机会。

    物品与装备

    品类：丹药 / 天材地宝 / 法宝 / 武器 / 衣物 / 材料。丹药、天材地宝可「使用」；法宝、武器、衣物可「装备」（武器/法宝槽位各 1 个，双持/多宝词条各 +1）；「弃」可丢弃。材料可在丹炉/炼器中炼丹炼器，产出品阶看材料与运气。

    稀有度（由获得难度决定）：凡品 / 灵品 / 玄品 / 仙品 / 神品，越难越强。词条三分流：金色机械词条有真实效果（修炼更快、护体、破劫、双持、多宝、锋芒、疾风、铁骨、噬血、回春、隐匿、破障、镇心、长青、气运、聚财、威仪、慧眼、逆天改命=免死一次）；灰色叙事词条纯趣味、无数值效果。带功能词条的法宝常驻生效：无需装备、不占法宝槽、不提供修炼倍率。探索掉物与凶险挂钩——境界越高，越要去凶险秘境才有高稀有度收获。

    战斗

    敌人境界 vs 你的境界决定受伤与致死：同级占优、越级凶险但高回报（掉高品阶装备）。战斗后有一行淡色结算。衣物/法宝减伤、武器降致死。

    死亡规则：只有叙事明确写死（殒命/气绝/身死道消）才会真正死亡。重伤到血尽、或高危行为触发死亡判定时，只会坠入「生死一线」濒死状态——下一回合是生死抉择：脱险即解除，应对不当才会死。渡劫失败例外：可能直接身死道消（可用回退一个回合）。

    关系与势力

    道侣 +25% 修炼、师徒 +20%、挚友/结义 +10%（取最高一档）；每个结盟势力 +5%（上限 +15%）。

    时间

    以"天"为粒度：短场景不流逝时间；闭关、赶路才推进。「闭关十年」一句话跨越十年，修为按十年放大，寿元与世界局势也如实流逝。

    选项说明

    难度：简单（受伤×0.7、灵石收益×1.25、突破+8%、致命行为坠入濒死 25%）/ 普通（基准：致命坠入濒死 40%）/ 困难（受伤×1.5、收益×0.85、突破-5%、致命坠入濒死 60%）/ 炼狱（受伤×2、收益×0.7、突破-10%、致命坠入濒死 85%）。高危行为坠入濒死的概率依次为 2%/5%/12%/25%；坠入濒死≠死亡，会有一回合脱险机会（见「战斗」里的死亡规则）。渡劫失败致死率随难度升降。节奏：快（成长 2 倍速）/ 慢。通关回合上限：超时未飞升则失败。修为增益：0.5x~5x。叙事篇幅：精简/标准/丰富。温度：输入框 ⚙ 里调（0.5 稳定 / 0.8 默认 / 1.2 奔放）。言出法随：外挂模式，心想事成、不会失败。

    存档

    每回合自动存档，另有 3 个手动档位。Key 只存你浏览器里。

    结局时（或存档面板）可选「导出本局日志」：完整对话与状态保存为 txt 到桌面（不含 Key），方便反馈意见给开发者。
