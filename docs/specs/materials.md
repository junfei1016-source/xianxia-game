# 材料体系（凡人修仙传 口径）

> 源码：`xianxia-game/public/materials.js`（数据与纯函数）、`public/game.js`（结算）、`public/world.js`（切片里的「可采」）。

## 一、四样性质

材料不是"炼丹时扣掉的字符串"，它至少带四样东西：

| 性质 | 取值 | 作用 |
| --- | --- | --- |
| **年份/药龄** | 十年 → 凡品；百年 → 灵品；五百年 → 玄品；千年 → 仙品；万年 → 神品 | **年份即品阶**，最硬的一条规则 |
| **五行** | 木 / 水 / 金 / 土 / 阴 / 雷 | 决定属性倾向（阴煞、雷击木等） |
| **用途** | 灵草灵花灵果灵液妖丹 → 炼丹；矿石妖骨妖皮灵木 → 炼器；灵木灵液 → 制符 | 品类 `kind` |
| **毒性** | 阴煞之气、血煞石、生魂、蚀骨花… | 炼丹损德、服之伤身 |

矿石、妖丹、妖血这类**没有药龄**的材料，用录入时的 `tier` 直接定阶（星砂=玄品、陨铁=仙品、妖丹=灵品）。

## 二、品阶与价目

| 品阶 | 年份下限 | 参考价（下品灵石） |
| --- | --- | --- |
| 凡品 | 十年 | 10 |
| 灵品 | 百年 | 200 |
| 玄品 | 五百年 | 2000 |
| 仙品 | 千年 | 30000 |
| 神品 | 万年 | 400000 |

## 三、产地

每件材料带 `regions`，世界切片的「可采」就按当前区域列出来（每域最多四样）：

```
【世界切片】… 物价×1.00；本地产出上限灵品。
可采：灵草（凡品）、三七草（凡品）、解毒草（凡品）、灵泉水（凡品）。
```

- 寒渊海：寒铁、万年灵乳、千年血参…
- 星陨荒原：星砂、陨铁、结金草、破障花…
- 万妖岭：妖王真血、化形果、凝婴果、大衍神木…
- 太清仙域：太清灵液（凡界去不了）

模型不许凭空报出产地之外的天材地宝。

## 四、与炼丹的关系

`materialBrewBonus(materials)`：材料的品阶越高，成丹越稳，**每阶 +3%，封顶 +15%**。

```
成丹率 = 丹方基础率 × 火源（地火 ×1.25） + 材料加成
```

这也是原著里"用百年灵草炼不出好丹，得用千年份"的数值化。

## 五、名字匹配规则

只认两种写法：

1. 名录全名（`星砂`、`回春草`）；
2. **年份前缀 + 名录名**（`百年回春草` → 回春草）。

不做任意子串匹配——否则「玄铁甲」会被当成「玄铁」（那是衣物，不是材料）。这条有测试守着。

## 六、待办

- 材料没有**采集流程**（采药/挖矿/猎妖仍是叙事 + `itemChanges`）；
- 五行只作数据，尚未参与炼丹的"相生相克"判定；
- 灵田/药园与掌天瓶式催熟没做（催熟本质是"年份 +100 年"）；
- 材料不能交易（`trades` 只认丹药/丹方/法宝）。
