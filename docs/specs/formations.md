# 阵法体系（凡人修仙传 口径）

> 源码：`xianxia-game/public/formations.js`（数据与纯函数）、`public/game.js`（布阵、撤阵、效果结算）。

## 一、原文依据

- **阵旗、阵盘**是"易携带好布置"的阵法类法器，但用它一般布不出厉害的**禁法大阵**（第 221 章）；
- 大阵要靠地脉、阵基，护山、封城、困妖都用得上；
- 阵法有困、杀、护、幻、传送、封印之分；破阵要找阵眼或者以力破之；
- 高阶阵法极耗灵石，对布阵者修为有要求。

落到代码就是两条线：**四级以下 = 阵旗阵盘可携带；五级起 = 大阵，借地脉。**

## 三、类型与效果

| 类型 | 效果 | 用途 |
| --- | --- | --- |
| 聚灵 | 修炼收益 ×1.08~×1.30 | 洞府闭关 |
| 护山 | 受伤 ×0.92~×0.70 | 守洞府、护宗门 |
| 杀伐 | 致死 ×0.88~×0.60 | 阵中迎敌 |
| 幻术 | 闭关被打断概率 ×0.85~×0.30 | 藏身、防仇家 |
| 传送 | 从本域出发路程 ×0.5 | 万里通行 |
| 困敌 / 封印 | 叙事控制（困住、封灵脉） | 捕妖、封禁 |
| 综合 | 全项小幅（周天星斗大阵） | 传说级 |

**同类效果取最强，不叠加**——两座聚灵阵不会叠成 ×1.3。

## 五、规则

- 布阵 `setFormation {name}`：修为够、灵石够、同地不重复、**同时最多两座**；
- 撤阵 `dismantleFormation {name}`：小阵收回阵旗阵盘，大阵撤走即废（不退灵石）；
- 效果由系统结算，模型不得直接改数值。

## 六、待办

- 没有**破阵**：敌方阵法只能靠叙事绕开，没有"找阵眼/以力破阵"的判定；
- 阵法不能升级、不能用材料加固；
- 没有阵基/地脉的选址规则（大阵在任何地方都能布）；
- 传送阵没有"两端成对"的限制。
