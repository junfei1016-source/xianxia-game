## 二、四艺与五级造诣

符箓、阵法、丹道、炼器；每 100 点经验升一级：

| 等级 | 经验 |
| --- | --- |
| 未入门 | 0 |
| 初窥门径 | 100 |
| 略有小成 | 200 |
| 登堂入室 | 300 |
| 炉火纯青 | 400 |
| 出神入化 | 500 |

## 三、两条提升路

1. **自练** `practiceCraft {skill, days}`
   - 每 3 日约 +9 经验（1~10 日可调）；
   - 等级越高越慢：`进益 = 天数×3 ÷ (1 + 等级×0.35)`。
2. **求教** `studyCraft {skill, from: "师父"|"玉简"}`
   - **师父**：须有师徒名分且信 ≥60，一次 +60 经验（按等级衰减 0.2）；
   - **玉简**：一面玉简读一次，+40 经验；新得玉简用 `newJadeSlip {name, skill}` 登记。

## 四、造诣的用处

| 技艺 | 加成 |
| --- | --- |
| 丹道 | 成丹率 +2%/级 |
| 炼器 | 成器率 +2%/级 |
| 阵法 | 破阵率 +3%/级；布阵花费 −5%/级 |
| 符箓 | 成符率 +3%/级；符威 +10%/级 |

## 五、符箓

| 阶位 | 造诣要求 | 基础成符率 | 例 |
| --- | --- | --- | --- |
| 凡符 | 未入门 | 85% | 疗伤符、金刚符、神行符 |
| 灵符 | 初窥门径 | 60% | 火球符、剑符、雷符 |
| 宝符 | 略有小成 | 40% | 回春符、遁地符、封灵符 |
| 仙符 | 登堂入室 | 20% | 仙符·太清 |

- 画符材料：符纸 + 朱砂（凡）；高阶加灵墨、妖血、太清灵液；
- 失败出「废符」，材料照扣；
- **用符**：疗伤符立刻回血；护身/神行/伤敌给 1~3 个月的符力（受伤↓、路程↓、致死↓），过期即散；
- 符箓造诣越高，符威越强（每级 +10%）。

## 六、珍材代地脉

灵气 <3 的地方布大阵，可以用**三份灵品以上材料**代地脉，材料耗尽、阵照成。
回执写"此地地脉不足，以三份珍材代脉"。

## 七、瓶颈与顿悟（第 9、15 章）

- 第 9 章："只隔着薄薄一层纸，再加把劲就突破瓶颈"；第 15 章：韩立遇练功瓶颈，靠药物续着。
- 规则：**略有小成（2 级）起，经验卡在 99**（`expCapFor`），自练与求教都只能到那层纸；
- 破法：**顿悟** `craftInsight {skill}`——须真到瓶颈；一次破一层，直接进下一级；
- 低阶（未入门→初窥门径→略有小成）不设卡，入门不难。

## 八、师承与叛门（第 27、338、347 章）

- **师父只教到登堂入室（3 级）**，再往上要靠自己；
- 师承记在 `player.craftMasters[技能]`；
- **叛门**：同一门技艺另投他师——旧师信任 −40、怨恨 +30，玩家声望 −10。原文里叛门背族要受抽魂之刑，这里先落到关系与声望上。

## 十、符力叠加与符阵

- **不同符并存**：最多三种，效果相乘（护身符 × 神行符各管一摊）；
- **同符续时**：再贴一张只延长时限，最多续到六个月；
- **符阵**：三张同符合成（须符箓「略有小成」），符威 ×1.5、时限翻倍。
