## 四、层次

- 每门 1~9 层；第 N 层要 `N×100` 火候；
- 修习 `practiceTechnique {name, days}`：每日约 +2~6 火候（层数越高越快）；
- 火候满且灵石够 → 自动破层，灵石 = 品阶价 ×（0.2 + 0.1×当前层）；
- 九层封顶。

## 五、主修

- 同时只吃一门主修；`setMainTechnique {name}` 可换；
- **转修散功**：换主修会散掉一成修为（旧功练出的法力要重炼）；
- 主修加修炼，炼体/剑诀/神识各吃各的。

## 六、秘密拜师败露

- 秘密拜师记在 `player.craftSecrets`；
- 每过一月掷一次：`2%/月`，旧师信任 ≥60 则 ×1.5，累计上限 85%（按月折进时间结算）；
- 败露：旧师信任 −40、怨恨 +30、声望 −10，记录清除——欺师灭祖坐实。

## 七、待办

- 灵根资质还没有接入（伪灵根应限制层数上限）；
- 功法没有"属性相克"与"改修相冲"（如火属功法改水属，应更痛）；
- 御兽类功法只有叙事，没有灵兽栏；
- 功法层数与境界突破尚未联动（筑基需基础功法七层那条线）。
