# 灵根（凡人修仙传 口径）

> 源码：`xianxia-game/public/roots.js`、`public/game.js`（测灵根、修炼倍率、功法层数上限）。

## 一、原文依据

- **第 127 章 灵根之说**：
  - 五行、甚至四属性混杂 → "修炼的效果可以说是惨不忍睹"，只能把炼气阶段五行基本功法**练至三、四层**就寸步不前，一生无望跨过筑基期——这种叫**伪灵根**；
  - 只有两、三种属性 → 修炼较快，叫**真灵根**；
  - 只有一种属性 → 叫**天根（天灵根）**，"上天的宠儿"。
- **第 144 章**：韩立"四属性缺金，属于伪灵根"，靠奇遇才到基础功法九层。
- **第 152 章**：掩月宗收了一名**天灵根**的小姑娘，各派震动。

## 三、变异灵根与异灵根

- **变异灵根**是"二种或三种五行属性变异"而成（第 127 章），每二三十年出现一个；**天根数百年才一个**——所以变异灵根比天根更常见；
- 异灵根各有偏长：

| 异灵根 | 偏长 | 出处 |
| --- | --- | --- |
| 雷灵根 | 以破坏力著称（伤敌 ↓） | 第 152 章 |
| 冰灵根 | 冰系功法远胜同阶（护体 ↓） | 第 438 章 |
| 风灵根 | 身法轻快（行路 ↓） | 第 144 章 |
| 暗灵根 | 长于隐匿与破禁（破阵 ↑） | 第 256 章 |

## 四、规则

- `awakenRoots { roots: ['金','木',...] }` 测灵根：只认五行与雷冰风暗，去重，最多五属；
- **测出即定终身**；
- 未测灵根：不加不减，也不设上限；
- 灵根决定**能不能修属性功法**；
- 伪灵根修功：层数到上限后，回执写"再练也是空耗"；
- **伪灵根修五行道法没天赋**（第 242 章）：画符成功率 ×0.8；
- **补天丹洗炼**（第 490、541 章）：`refineRoots` 洗掉一属、资质上一档，须身上有补天丹；
- 天根结丹无瓶颈（第 241 章），目前仅作叙事提示。

## 五、待办

- 变异灵根的"二三种五行变异"来源还没在生成时体现（只判结果）；
- 天根结丹无瓶颈尚未接进境界突破；
- 伪灵根"一生无望筑基"未硬性接入（第 146 章"服用筑基丹希望也渺茫"）；
- 灵根对闭关、丹药吸收的额外影响未做。
