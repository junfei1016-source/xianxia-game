# 法宝体系（凡人修仙传 口径）

> 对应源码：`xianxia-game/public/treasures.js`（数据与纯函数）、`public/game.js`（结算）。
> 原则：**阶位与词条由名录定，模型只填名字**；名录外的法宝才沿用旧式 `grade/rarity`。

| 法器 | 炼气 | ×1.00 | 0 | 20 | 可 |
| 下品法宝 | 筑基 | ×1.15 | +3 | 200 | 可 |
| 中品法宝 | 筑基 | ×1.25 | +6 | 800 | 可 |

- 法器是炼气修士的常用之物，法宝需筑基以上才能真正驱动；

- 通天灵宝（第 641 章「虚天鼎」）；
- 玄天之宝（第 1359 章「玄天斩灵剑」，混沌万灵榜，通灵之宝）。

## 三、驱动规则（小说里"修为不够用不了"）

```
威力 = 阶位威力 × 驱动系数 × 本命加成（1.25）
驱动系数：够 = 1.0；差一个大境界 = 0.5；差两个以上 = 0
```

- 系数为 0 时**完全不加成**（占槽也不给修炼/防御）；
- 系数 0.5 时威力减半，低于 1 的修炼倍率会被下限保护吃掉——也就是"勉强驱动，聊胜于无"；
- 名录法宝**不再算"功能法宝"**（旧版会把上品法宝当成免费常驻，属漏洞，已修）。

## 四、本命法宝

`refineTreasure: [{ name }]`

- 须**金丹以上**、且不是法器；
- 一名修士**只能有一件**；
- 代价：三成气血 + 三成阶位价（灵石）；
- 收益：威力 ×1.25，与心神相连（叙事上不易被夺）。

## 五、交易

- 法器～极品法宝可按阶位价买卖（区域物价 × 声望议价，卖价 55%）；
- **古宝以上不流通**：`itemPrice` 返回 null，交易直接拒绝——"这种东西不是灵石能买的"。

## 六、与旧体系的关系

| 情况 | 规则 |
| --- | --- |
| 名录内法宝 | 阶位 + 词条由表定；忽略模型自报的 grade/rarity |
| 名录外法宝/武器/衣物 | 沿用 grade（基础/玄阶/地阶/天阶/仙阶）× rarity |
| 防御型（盾/幡/网/镜/塔/钟/印/珠） | 按阶位威力减伤 |
| 攻击型（飞剑/刃/钉/扇/梭） | 按阶位威力降低致死 |

## 七、待办

- 没有**法宝毁损/自爆/夺宝**；

- 名录之外的法宝仍由模型命名，品阶自报——后续可加"名录扩充 + 越级校验"。
