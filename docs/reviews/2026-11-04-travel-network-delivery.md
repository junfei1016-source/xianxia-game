## 一句话

上一轮把地名换成了原著的，这一轮把**构架**立起来：地图分"界 → 大区 → 区域"，路分"陆路 / 海路 / 古传送阵"。跨海不再是一串大数字，而是一道**要灵石的门**。

## 结构

```
界（凡界/灵界）
 └ 大区（天南 | 乱星海 | 灵界）
    └ 区域（国 / 坊市 / 草原 / 岛 / 边城）
```

| 大区 | 区域 | 走法 |
| --- | --- | --- |
| 天南 | 越国·建州、黄枫谷坊市、元武国、天罗国、慕兰草原 | 互相陆路，不花钱 |
| 乱星海 | 尾星岛、天星城、奇渊岛 | 互相海路（租舟） |
| 灵界 | 天渊城 | 到不了，只能飞升 |

**古传送阵**（`GATES`）：建州太岳山脉 ↔ 外海尾星岛，1 日、200 灵石。其余跨海组合不连通。

## 接口

```js
MACROS                       // 三个大区
REGION_META                  // 每域 → { macro, kind }
GATES                        // 传送阵表（点对点、日数、灵石）
macroOf(region) / gateBetween(a, b)
travelPlan(fromId, toId, world) -> { days, mode: '陆路'|'海路'|'传送阵', cost, note } | null
moveToRegion(world, id)     // 现在返回 { from, to, days, mode, cost, note }
```

2. **回程也走传送阵**：`天星城 → 尾星岛` 同在外海，是海路不是阵——测试里我一开始写反了，顺手改成断言海路，另加一条 `尾星岛 → 建州` 必须走阵。
3. 文件是 CRLF，用脚本替换必须归一化再写回，否则 `includes` 匹配不到（这次踩了两次）。
