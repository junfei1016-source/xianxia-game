## 本轮确立的玩法规则

1. 玩家属性只接受有限、安全的 delta，保留裸数字和平铺字段兼容；直接 set 一律拒绝，不能绕过难度、收益倍率或外挂免伤。倍率、物品步进取整和加法后再次检查安全范围。
2. 非法字段或数组条目单独拒绝，合法独立内容继续落地。根不是普通对象时整份拒绝，不增加回合、不推进日期/大势/任务期限、不改变防刷状态或压缩记忆。
3. 已完成、失败、放弃的任务不能由模型改写或重开；重复同一终态不补造事迹。完成/失败同批冲突按任务拒绝，不影响其他合法更新。放弃由玩家按钮触发。
4. 对应任务的精确系统事迹标签由实际状态迁移生成，不能利用 newEvents 另写相反结果；包括本回合刚登记的新任务。
5. 普通剧情 flags 仅允许布尔值；保留标记不能伪造或撤回。保留 deathImminent/qiDeviation 的 false 清除通道。物品数量必须明确，退款还必须为正数。
6. 被拦截时显示系统说明，以面板和存档为准。境界动画、目标提示来自真实状态变化，不依据模型自报成功。

第一轮日期规则保持不变：30 天/月、12 月/年、截止当日有效、同回合完成优先、旅途末接取锚点、旧期限待确认、读档不判罚。

## 独立审查中发现并修复

- JSON 根数组被截取内部对象；null 直接进入结算抛错。
- NaN/Infinity、倍率/加法溢出及月份与日历加法边界污染状态。
- set 绕过外挂伤害豁免；非法/缺失物品数量默认增加一件；负退款取绝对值变成奖励。
- 已完成→失败等终态覆盖；同批完成/失败冲突；newEvents 提前伪造相反任务状态，包含新任务场景。
- aliasMap/关系档案把 toString 等名称误读成原型函数；前端事迹分类和分组亦存在同类问题。改为自有属性读取和无原型字典，并用真实界面验证。
