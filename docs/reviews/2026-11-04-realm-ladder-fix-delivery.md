# 第三十九轮交付：v1.37.2 补回「炼虚」三阶

日期：2026-11-04。分支 `codex/state-input-guards`，从 `d3e9ebf` 继续。只做本地提交。

## 怎么发现的

用户看页面时问「没有炼虚啊」。我先以为是自己版本判断错，去查文件才发现：
**境界阶梯里真的没有炼虚**，是我上一轮说错了话——但用户的观察戳出了一个持续几十轮的真 bug。

## 原文依据（第 127 章《灵根之说》）

> 修仙者按照境界划分，应分为下境界、中境界以及上境界三大阶段。下境界包括了炼气、筑基、结丹、元婴、化神等五层，中境界有炼虚、合体、大乘三层，到了上境界其实只剩下渡劫这一层关口了，过了此层就可飞升仙界。

第 1219 章另给天劫节奏：「下境界的元婴和化神修士，是每三百年经历一次天劫……中境界的炼虚和合体、大乘期的天劫，是三千年一次」——同样把炼虚算在中境界最前一档。

## 缺口有多大

`REALM_LADDER`（唯一事实源）从 v1.1.x 起就是「化神后期 → 合体初期」，**没有炼虚**。而按含炼虚写的地方有六处：
`formations.js`（九级阵法 minRealm 炼虚）、`pills.js`、`techniques.js`、`treasures.js`、`world.js`（REALM_RANK）、`game.js` 自己的 `REALM_MIN_YEARS` 与 `MAJOR_ORDER`。

后果：

1. 玩家从化神后期直接"跳"合体，炼虚整段不存在；
2. 阵法九级、以及任何写着"炼虚"要求的功法/法宝/丹药**永远够不着**（判定用的是 `realmIndex`，而 `realmIndex('炼虚初期')` 返回 0 = 凡人）；
3. `realmMajor('炼虚初期')` 也匹配不到，寿元/气血、最少在境年限全部落到默认值。

## 数值取舍（原文没有的，标明）

炼虚的寿元/气血（2100 / 2600）取化神（1500/2000）与合体（3000/3500）的几何中点。原文只给境界顺序与天劫节奏，没有逐阶寿元数，所以这是玩法取舍，不是考据结论。最少在境年限沿用已有的 `炼虚: 400`。
