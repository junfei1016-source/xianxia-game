# 第十二轮交付：护法——关系网第一次直接影响闭关（v1.10.0）

日期：2026-11-02 ｜ 范围：把「护法」接进闭关打断

## 问题

上一轮闭关会被打断，但玩家只能干挨着——仇家上门、心魔发作，全是随机。
而前几轮辛苦建的**关系网**（信/需、道侣、结义）在闭关这件事上一点用都没有，
等于"关系只是面板上的数字"。

## 做法：信得过的人来守门

```
道侣 / 结义 / 师徒 / 挚友，且 信 ≥ 60  → 自动护法
「请顾长歌护法」点名相请，且 信 ≥ 50   → 也算
怨 ≥ 50                               → 一律不护（哪怕名分是道侣）
最多两位，多了不叠加
```

每位护法把**被打断的概率压到 55%**（0.55 的 n 次方，n 为护法数），下限 2%。

| 场景 | 无护法 | 一位道侣护法 |
| --- | --- | --- |
| 青芜国（危险 1）闭关 | 10% | 5.5% |
| 寒渊海（危险 5）+ 乱世 | 28% | 15.4% |
| 加三个仇家 + 走火入魔 | 50%+ | 27.5%+ |

## 两套文案

- 没被打断：【护法在侧】写他们轮值、布阵、驱赶闲人，出关提一句辛苦；
- 被打断：写明"替你挡下第一波"，并给护法**信任 +5**——护主一次，关系更铁。

护法只作用于当回合，结算后清空。

## 设计取舍

- **护法不加速修炼**：只保平安。否则"带满道侣"会变成最优解，关系沦为 buff。
- **上限两位**：防止堆人头。两位之外的人不会出现，也不会被记恨。
- **点名也要看信**：信 40 的"挚友"请不动——名分不等于交情，这与四维账本的口径一致。
- **仇人优先当打断者**：如果 world 里既有护法又有仇人，仇人仍会来，只是被挡住——这是有意的：护法不是免疫，是减压。

## 遗留

- 护法的人选不会"消耗"：没有受伤、没有闭关期间的支线，只是概率修正。
- 没检查护法是否**在场**（同区域/是否活着），NPC 没有位置与生死状态。
- 结盟势力（factions）还没进来：理论上"宗门派人护法"也该算，目前只看 NPC。
- 文戏上，护法者没有自己的台词与动机——只有系统一句"替你挡下第一波"。
