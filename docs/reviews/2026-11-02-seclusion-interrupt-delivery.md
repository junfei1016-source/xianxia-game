# 第十一轮交付：闭关会被打断（v1.9.0）

日期：2026-11-02 ｜ 范围：把闭关从"点一下等十年"变成有风险的选择

## 问题

上一轮把闭关改成按时长结算之后，节奏对了，但**闭关成了纯收益**：点一句"闭关六十年"，
岁月照走、修为照涨，没有任何东西会来搅局。小说里恰恰相反——韩立每次闭关都要防仇家、
防心魔、防兽潮，出关往往不是圆满，而是"被迫出关"。

## 做法：先掷骰，再写叙事

闭关不是结算里的事后惩罚，而是**开口之前先掷**：

1. 玩家输入里有闭关意图（`闭关|坐关|闭死关|苦修|静修|入定`）；
2. 引擎掷一次，算概率：

```
基础 8%
+ 区域危险度 × 2%
+ 乱世 / 正魔大战 5%
+ 敌对势力数 × 5%（上限 15%）
+ 结仇 NPC 数 × 3%（上限 9%）
+ 走火入魔 +10%
封顶 60%
```

3. 掷中后定两件事：**第 1~3 年出岔子**、**谁上门**（优先结仇最深的 NPC → 敌对势力 → 心魔/不速之客）；
4. 把结果写进本回合指引，逼 GM 写"提前出关"；
5. 结算时把 `timeMonths` 压到那一年，修为按实际年数算，记一笔「闭关受扰」；
6. 只用一回合，用完即清。

## 指引长这样

```
【闭关将被打断】这次闭关不安稳：第 2 年，血刀寨 找上门（或心魔发作）。
本回合叙事必须写"被迫提前出关"——先写闭关所得，再写打断那一刻的冲突与代价；
timeMonths 只填这 2 年（约 24 月），不得写完整闭关，也不得把修为写成圆满。
```

## 效果对比

| 情况 | 以前 | 现在 |
| --- | --- | --- |
| 在安全的新手国闭关 | 稳拿六十年修为 | 约 10% 概率被打断 |
| 在乱世 + 寒渊海（危险 5）闭关 | 稳拿 | 基础 8% + 10% + 5% + 仇家加成，常常过半 |
| 有 3 个仇人 + 走火入魔 | 稳拿 | 封顶 60% |

玩家想安稳闭关，就得先清仇家、挑安全地带、别在走火入魔时硬关——**选择有了代价**。

## 遗留

- **没有"硬闯闭关"**：现在打断必然生效，玩家没有"顶着打扰继续闭关"的选项（那应该是一次冒险判定）。
- **打断的后果还太轻**：只压时长、记一笔，没有受伤/走火入魔/损失丹药。
- 没有"护法"概念：道侣/师徒/结盟势力本可降低被打断的概率，现在还没接。
- 概率是工程取值，`rollSeclusionInterrupt` 可注入随机源，调参只需改公式。
