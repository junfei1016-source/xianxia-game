# 第二十五轮交付：采集点与炼器（v1.23.0）

日期：2026-11-03 ｜ 范围：采集从"一次结算"变成有地点、会枯竭；五行接进炼器与法宝驱动

## 一、采集点

每个区域按采集类型生成固定几处：

| 采集类型 | 采集点 | 恢复周期 |
| --- | --- | --- |
| 采药 | 药圃 | 12 个月 |
| 挖矿 | 矿脉 | 8 个月 |
| 猎妖 | 妖巢 | 10 个月 |

- 首次在某区域采集时生成（最多三处，取当地材料池）；
- 采一处 → 该处 `harvestedMonth = 当前月`，按周期恢复；
- **全部采空** → 只能野外碰运气，一次一份，回执写"附近的采集点都已枯竭"；
- 境界不够的采集点直接跳过（星陨矿脉对炼气修士不可采）。

## 二、炼器

`forge: { name, materials: [材料名], fire: '真火'|'地火' }`

- **只炼名录里的法宝**："名录外的器物，炼器谱上无名"；
- 至少两味材料，且必须在背包里；
- 成器率（真火基准）：法器 90%、下品 60%、中品 45%、上品 30%、极品 20%、古宝 12%、灵宝 8%、通天 5%、玄天 2%；
- 成功入包、失败出「废器」，**材料照扣**。

## 三、五行配材（炼器）

| 关系 | 调整 |
| --- | --- |
| 材料与法宝同属 | **+6%** |
| 材料生法宝 | +4% |
| 材料克法宝 / 被法宝克 | **−8%** |
| 地火炼火属法宝 | +5% |
| 封顶 | −20% ~ +25% |

例：炼「青竹蜂云剑」（木属）——用灵草（木，同属）+ 雷击木（雷，无关系）加成；用玄铁 + 赤铜（金克木）减成。同一掷点，前者成、后者废。

## 四、法宝相冲（驱动）

同时装备两件**五行相克**的名录法宝，双方 `conflict = true`，威力 ×0.5：

- 火克金：赤焰旗（火）× 玄铁飞剑（金）
- 金克木：玄铁飞剑 × 青竹蜂云剑
- 水生木（相生）不冲，木剑与火旗同列也无碍

这补上了"多宝"词条最需要的制约——不是槽位够就能随便堆。

## 六、测试日志

```
[离线测试] 采集点与炼器
ℹ tests 10  ℹ pass 10  ℹ fail 0
离线测试完成：32/32 套通过
```

写测试踩了三个坑，都值得记：

1. 以为"采一次就枯竭"——其实一个区域有三处采集点，要采空三处才会枯竭；
2. 拿「天雷竹」当炼器材料——它是**法宝**不是材料，材料里对应的是「雷击木」；
3. 以为水属材料会克木剑——实际是**水生木（相生）**，克木的是**金属**。五行写反了，测试当场指出。

## 七、遗留

- 采集点没有"矿脉品质/灵田等级"，也不会因大势（秘境将启、正邪大战）变化；
- 炼器只吃"材料名"，没有丹方式的炼器谱（材料组合固定与否未定义）；
- 法宝相冲只作用于修炼/防御倍率，战斗叙事里没有"相冲反噬"；
- 灵田/催熟仍未做。
