# 第四十轮交付：v1.38.0 世道不再报名（征兆分层 + 传闻）

日期：2026-11-04。分支 `codex/state-input-guards`，从 `0b903ff` 继续。只做本地提交。

## 一句话

「天下大势：乱世」这块牌子撤掉了。世界改由三层征兆（天时／市面／人事）与街谈巷议（传闻）说话，
玩家自己拼出现况；境界越高，看得越清，也越能听出谁在胡说。

## 为什么这么改

用户的原话是"我不想让它在明面上出现，我想给它变成一种我也说不上来的东西"，并选中了「传闻化」与
「境界限定感知」两条。原文也没有这个分类：韩立从不看"当前大势"，他知道的是米价、溃兵、封山、
灵气变薄（第 172 章禁地圈封、第 220 章灵气分布不均）。所以标签退回成征兆。

## 规则

**征兆分层（`skyOf` / `perceptionTier`）**

| 境界 | 看到什么 |
| --- | --- |
| 凡人 · 炼气 | 一句模糊的："近来总觉得不大对劲，却说不上来。" |
| 筑基 · 金丹 | 天时 + 市面（两句具体） |
| 元婴以上 | 天时 + 市面 + 人事（三句），且能听出假传闻 |

句子由内部底子（五种）在各自的池子里挑，按 `(底子, 回合, 年)` 派生，同一回合多次渲染不闪。
**任何一句都不含时代名**——这条由测试守死。

**传闻（`ensureRumors` / `spawnRumor` / `resolveRumors` / `tickRumors` / `rumorsFor`）**

- 每三回合冒一条；来源从「茶馆掌柜、行商、同门师兄、坊市药童、樵夫、酒肆散修、游方道人、驿馆伙计」里挑。
- 六成是真话（照当前底子的征兆说），四成是掺的（拿别个底子的说法冒充）——所以玩家可以对照所见（米价、关卡）识破。
- 三回合后水落石出：真的写「应验」、假的写「是虚的」，都进事迹；图鉴里能回看最近几条。
- 元婴以上，未揭晓的假传闻会带一句「（你听着不像实话）」——这是境界的实利。

| 语法 | `node --check` game/app/world 全过 |

过程中修掉的三个真问题（都是冒烟逼出来的，不是猜的）：

1. `skyRowsHtml` 用了 `renderStatus` 里的局部 `tip` 函数 → 报 `tip is not defined`，前端直接崩。改为把 `tip` 作参数传进去。
2. 冒烟脚本从 `scripts/` 里用 `new URL(...).pathname` 拼路径，中文目录被 percent-encode → 导入静默失败（退出码还是 0）。改用 `fileURLToPath`，并给导入加了 try/catch，失败会进 `运行时错误` 数组。
3. `test_era_timeline.mjs` 三条断言按旧契约写（期待"大势期限已至""大势已变"）。契约是这轮**故意**改的，所以改测试——并顺手把断言加强成"提示里不得出现时代名"。

## 试玩怎么感受

1. 新开一局：开局不再有「【天下大势】乱世」，而是「【世道】…」＋一两句天时（凡人开局只有一句模糊的）。
2. 右侧状态面板：原来那行「大势 乱世」变成「天时」「市面」（筑基后）或三行（元婴后）。
3. 打到第 3、6、9… 回合，会冒出一条传闻；同一句话三回合后会被揭晓"果然如此"或"那话是虚的"。
4. 想自己试各种底子：地址栏加 `?dev=1`，⚙ 面板里会多出「世道底子（调试）」。

## 仍需用户决定

1. 凡人那段"说不上来"会不会太闷？可以改成给两档模糊（"有点不对"／"明显不太平"）。
2. 传闻的频率（三回合一条）与真假比例（六四开）要不要调。
3. 要不要让玩家能主动"打听"（花一块灵石问掌柜，换一条更准的传闻）——这样"能查但不可名"就更实。
