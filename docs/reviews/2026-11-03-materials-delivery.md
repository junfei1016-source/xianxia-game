# 第二十三轮交付：材料按小说定性质（v1.21.0）

日期：2026-11-03 ｜ 范围：材料从"炼丹扣掉的字符串"变成有年份、五行、产地、毒性的东西

## 问题

炼丹的 `recipe.materials` 里一直只是名字：灵草、妖丹、万年灵乳。
系统按名字扣数量，却不知道"灵草"值多少、"万年灵乳"为什么贵、"星砂"长在哪。

## 做法

新增 `public/materials.js`，四十种材料，每件四样性质：

| 性质 | 规则 |
| --- | --- |
| 年份 | 十年凡品、百年灵品、五百年玄品、千年仙品、万年神品 |
| 五行 | 木/水/金/土/阴/雷 |
| 用途 | 灵草灵花灵果灵液妖丹→炼丹；矿石妖骨妖皮灵木→炼器；灵木灵液→制符 |
| 毒性 | 阴煞、血煞、生魂、蚀骨花（炼丹损德） |

矿石妖丹没有药龄，用录入阶位：星砂=玄品、陨铁=仙品、妖丹=灵品、生魂=仙品。

## 接进已有系统

1. **世界切片**：每域列「可采」四样，寒渊海出寒铁与万年灵乳，星陨荒原出星砂与陨铁。
2. **炼丹**：`materialBrewBonus` 按材料品阶加成成丹率，每阶 +3%、封顶 +15%——用百年灵草和用千年血参，成丹率不一样。
3. **入包归一**：`itemChanges` 收到「星砂」时，品类、五行、年份由表定，模型写的 `grade: 天阶` 不作数。
4. **提示词**：材料只填名字，品质靠年份；不许凭空报出产地之外的天材地宝。

## 踩到的坑

材料名录里有「玄铁」，而基础套件里有一件测试衣物叫「玄铁甲」。
最初的 `materialByName` 用任意子串匹配，于是「玄铁甲」被当成材料、装备互斥测试当场红。
改成**只认「全名」与「年份前缀+全名」**两种写法，并补了一条断言钉死（`materialByName('玄铁甲') === null`）。

## 遗留

- 没有采集流程：采药/挖矿/猎妖仍靠叙事 + `itemChanges`；
- 五行还没参与炼丹的相生相克；
- 灵田/药园与掌天瓶式催熟没做（催熟本质是"年份 +100"）；
- 材料不能交易（`trades` 只认丹药/丹方/法宝）。
