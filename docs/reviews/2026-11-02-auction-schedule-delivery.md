# 第十八轮交付：拍卖会改成会期制（v1.16.0）

日期：2026-11-02 ｜ 范围：把拍卖从"随时可点的按钮"改成"一年两度的事件"

## 问题

上一轮的拍卖会随时能举牌——玩家想拍就拍，没有错过、没有等待，拍卖就只是"一个更贵的商店"。
但《凡人修仙传》里的拍卖会是有排期的：**定期开、错过要等下一场**，才有"赶会"的紧迫感。

## 做法：每年 3 月、9 月各一场

```
AUCTION_MONTHS = [3, 9]
会期内：照常举牌，价高者得
会期外：拒绝，并告诉你下一场在几月、还有几个月
```

- 落霞坊才有，且必须**同时满足地点与会期**；
- 跨年自动推算：十月之后是次年三月（还有 5 个月）；
- 每回合提示词报排期：
  - 会期：`【拍卖排期】本月正是落霞坊的拍卖会（每年 3 月、9 月各一场）……`
  - 非会期：`【拍卖排期】落霞坊下一场拍卖在 X 年 X 月（还有 N 个月）。不在会期不能举牌，可写打听拍品、托人留位、攒灵石的铺垫。`
- 不在落霞坊时不报排期，避免无谓提示。

## 为什么这样有意义

排期把"钱"和"时间"绑在一起：想拍禁制丹方，得先攒够灵石，还得在三月或九月赶到落霞坊。
**错过就是半年**——这半年正好够一个筑基修士闭关一次，或者跑一趟远路。

## 遗留

- 会期只有"开/不开"，没有"拍品清单"：每场拍什么仍由 GM 现编，不能提前公布。
- 没有"大拍/小拍"之分：原著里十年一度的大拍与常年小拍是两种场面。
- 拍卖对手仍是隐形的一手，没有具体 NPC 与恩怨。
