# 第二十六轮交付：采集点按稀有度分级（v1.24.0）

日期：2026-11-03 ｜ 范围：采集点不再是"随机抓一种材料"，而是按地气分稀有度

## 问题

上一轮的采集点只从"区域材料池"里随机抓一种：青芜的药圃可能直接长出玄品灵草。
这跟小说里"灵气越足、越凶险的地方才出高阶灵药"完全相反。

## 做法

### 1. 稀有度上限由「灵气 + 危险」定

| 区域 | 灵气+危险 | 可出上限 |
| --- | --- | --- |
| 青芜国 | 2+1=3 | 凡品 |
| 落霞坊 / 赤沙荒原 | 4 / 5 | 灵品 |
| 大衍王朝 / 归墟城 | 6 / 7 | 玄品 |
| 寒渊海 / 万妖岭 / 星陨荒原 | 8 / 9 / 8 | 仙品 |
| 太清仙域 | 灵气 6 | **神品** |

### 2. 越高阶越罕见

出点权重 `6 : 4 : 2 : 1 : 0.5`（凡→神）。同一片药圃，多数是凡品，偶得一株仙草。

### 3. 恢复周期随稀有度

| 稀有度 | 恢复 |
| --- | --- |
| 凡品 | 6 个月 |
| 灵品 | 12 个月 |
| 玄品 | 24 个月 |
| 仙品 | 48 个月 |
| 神品 | 96 个月（八年） |

### 4. 收成随稀有度递减

凡品/灵品按天数（四天一份），玄品一茬至多两份，**仙品以上一次只出一份**——
千年灵药不会成捆地长。

### 5. 回执带稀有度

```
【采集】采药 8 日：在药圃（凡品）采得「灵草」，灵草×2
```

## 遗留

- 采集点稀有度在**生成时定死**，不会随大势（秘境将启、灵气复苏）升格；
- 没有"矿脉品质/灵田等级"这类可经营的提升；
- 稀有度只影响材料，不影响"危险度"（仙品药圃旁边该有妖兽守着，还没做）。
