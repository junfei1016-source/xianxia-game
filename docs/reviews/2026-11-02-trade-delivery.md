# 第十六轮交付：交易结算（v1.14.0）

日期：2026-11-02 ｜ 范围：丹药与丹方的买卖走规则层

## 问题

上一轮丹方有 `price`，但没有交易流程——"在坊市买一份丹方"仍然只是叙事，
模型说花多少就花多少，甚至可能不扣钱。灵石的消费一直是最容易被忽略的一环。

## 做法：一个 `trades` 字段

```
trades: [{ action: 'buy'|'sell', item: '回春丹', qty: 2 }]
```

价格由系统算，不由模型报：

```
买入价 = 丹价 × 区域物价系数 × 声望议价
卖出价 = 买入价 × 55%
```

- **区域物价系数**来自世界骨架（青芜 1.0、落霞 0.9、赤沙黑市 2.0）；
- **声望议价**：声望 70 约让利 8%，声望 20 约抬价 12%，夹在 0.8~1.3；
- **55% 回收**：堵住"买来卖去"刷钱。

丹方按来源定价（`recipeOf().price = 丹价 × 来源系数 × 3`）：常见便宜、上古贵六倍。

## 拒绝也有理由

| 情况 | 结果 |
| --- | --- |
| 灵石不够 | 拒绝，钱货不动 |
| 货不够 | 拒绝，一件不扣 |
| 丹方已经会了 | 拒绝，不重复扣钱 |
| 叫不上价的杂物 | 拒绝（杂物仍按叙事处理） |

## 一个命名统一

丹方名从「回春丹丹方」改成「**回春丹方**」（丹名 + 方）。交易、炼制、已知丹方三处共用同一套名字——
之前正是这个名字不一致，导致"买丹方"时找不到对应的丹。

## 遗留

- 只结算**丹药与丹方**，法宝/材料/杂物仍靠叙事——它们没有统一价目表，硬编会失真。
- 没有"讨价还价"：声望决定价格，但玩家不能当场砍价。
- 黑市（赤沙）价格翻倍，但没有"禁物"限制——理论上黑市该卖禁制丹方。
- 拍卖会还是叙事，没接竞价机制。
