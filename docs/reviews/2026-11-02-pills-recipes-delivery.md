# 第十五轮交付：丹库与丹方体系（v1.13.0）

日期：2026-11-02 ｜ 范围：扩充丹药品种，补上丹方四类与炼丹

## 补的是什么

上一轮只有 12 味丹、只能买和捡。这一轮把《凡人修仙传》里"丹方"这一层补上：

| 丹方来源 | 特点 | 原文依据 |
| --- | --- | --- |
| 常见 | 坊市有卖，丹方烂大街 | 第 156 章"各派都有玄阳火地" |
| 上古 | 遗府残卷，药力强、成丹难（成丹率 ×0.7、价 ×6） | 上古秘境、古修遗府 |
| 残缺 | 只余残页，**三张拼齐才能开炉** | 残卷、虫蛀玉简 |
| 禁制 | 魔道禁丹，炼之损德、服之伤身 | 血煞丹一类 |

## 丹库：30 味

疗伤 6（止血散→九转还魂丹）、聚气 5、破境 3（筑基丹/结金丹/凝婴丹）、延寿驻颜 3、解毒 3、洗髓 2、禁制 2（蚀骨丹/血煞丹）、特殊 2（化形丹/太清丹）。

每味带：品阶、适用境界、功效、参考价、**所需材料、基础成丹率、丹方来源**。

## 炼丹

```
brewPills: [{ recipe: '回春丹方', fire: '地火' }]
```

1. 查丹方是否存在、是否拼齐（残缺未齐直接拒）；
2. 查材料（背包里按名字数量核对，缺一味就拒，**不动任何材料**）；
3. 扣材料 → 掷成丹率 `丹方基础率 × 火源（地火 ×1.25）`；
4. 成功出丹，失败出「废丹」，材料不退。

## 新输出字段

| 字段 | 用途 |
| --- | --- |
| `newRecipes: [{name, pill, source}]` | 玩家真正拿到手的丹方 |
| `recipePieces: [{name, delta}]` | 残缺丹方的残页 |
| `brewPills: [{recipe, fire}]` | 开炉炼丹 |

材料由系统扣，模型不得自己写丹药产出。

## 遗留

- **交易只给了价格，没有交易流程**：丹方有 `price`（按来源 ×3 倍左右），但"在坊市买丹方"仍靠 GM 叙事，没有结算接口。
- 炼丹没有"炼丹术熟练度"：现在只吃丹方与火源，不看玩家是不是丹师。
- 材料名是字符串匹配（"妖丹"和"三级妖丹"算两种），没有归一化。
- 禁制丹的"损德"只写在描述里，没有扣正邪值。
