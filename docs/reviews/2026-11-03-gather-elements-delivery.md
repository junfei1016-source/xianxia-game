# 第二十四轮交付：采集与五行炼丹（v1.22.0）

日期：2026-11-03 ｜ 范围：材料从"只存在于背包"变成"能采、能克"

## 一、采集

`gather: { kind: '采药'|'挖矿'|'猎妖', days: 1~30 }`

```
采药 → 灵草/灵花/灵果/灵液
挖矿 → 矿石/灵木/奇物
猎妖 → 妖丹/妖骨/妖皮/妖血
```

- **出什么由系统定**：按当前区域的常见材料（`materialsInRegion`）抽，模型只报"采药三天"。
- **境界压制**：材料的品阶 rank 不得高于玩家大境界 rank。炼气修士在星陨荒原挖不到星砂（玄品），系统直接拒绝："此地之物非你修为能取"。
- **天数换份数**：四天一份，三日一份、八日两份、三十日七份；耗时写进 `timeMonths`，日历照走。
- **野外有风险**：`风险 = (猎妖 15% / 其他 8%) + 危险度×2%`，掷中扣 6%~18% 气血，回执写明"遭了埋伏"。
- 无货的地界直接拒：仙域只有灵液，挖矿会说"没有可挖矿之物"。

## 二、五行炼丹

```
火炼之法：木生火（助燃）、雷助火；水克火、阴寒压火、火克金（耗火）
地火比真火更"火"，助与压都放大一半
加成范围：−20% ~ +20%
```

| 材料五行 | 对成丹率 |
| --- | --- |
| 木 | **+4%**（地火 +6%） |
| 雷 | +3%（地火 +4.5%） |
| 金 | −2%（火克金，耗火） |
| 水 | **−5%**（地火 −7.5%） |
| 阴 | −4%（地火 −6%） |

所以同一张丹方，用灵草（木）主药比用灵泉水（水）主药更容易成——聚气丹比化毒丹"好炼"，不是巧合。

最终成丹率：

```
丹方基础率 × 火源 + 材料年份加成（每阶 +3%，封顶 +15%） + 五行调整（±20%）
```

## 五、遗留

- 采集还是"一次结算"：没有采集点、没有刷新周期、没有矿脉/灵田；
- 五行只作用于炼丹，炼器与法宝驱动还没用上；
- 没有"灵田/药园/催熟"（掌天瓶式 +年份）；
- 采集产物不能直接交易。
