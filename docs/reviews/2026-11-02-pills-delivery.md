# 第十四轮交付：丹药系统（v1.12.0）

日期：2026-11-02 ｜ 范围：把丹药从"叙事里的一个道具"变成有规则的系统

## 为什么这不是小补丁

上一轮护法会受伤之后，最自然的想法是"给颗药就好了"。但《凡人修仙传》里，丹药本身是一整套设定：

| 原文 | 规则 |
| --- | --- |
| 第 243 章 | 服丹太频，身体产生**抗药性**，丹药慢慢失效 |
| 第 597—598 章 | 筑基期的丹药到结丹期**完全无效**——吸灵效率追上了天地灵气 |
| 第 156 章 | 炼丹借**地火**，成丹率远高于真火 |
| 第 397 章 | 买**丹方**、以妖丹配灵草批量炼制，才解决抗药性 |

所以这一轮做的是：品阶、适用境界、抗药性、功效四件事，而不是给一颗药加个数值。

## 三条硬规则

1. **模型不能再写药效**：本回合若服了认得的丹，`stateUpdates` 里的气血/修为正增量一律忽略，改由丹方结算。
2. **抗药性**：同一种丹第 n 次服，效果 ×0.75ⁿ（下限 0.15）；每半年不服则消退一次。
3. **跨境失效**：丹药只对不高于适用境界的人有用。结丹期服筑基丹药，只剩"丹力对你已无用处"。

另外丹名只认全名 / 量词前缀 / 括号后缀——"百转培元丹"是另一种丹，不会被当成"培元丹"。

## 以丹养伤

`treatNpc: [{name, pill}]`：用疗伤丹给负伤的护法缩短调养时间。
回春丹顶 1 个月、生肌丹顶 2 个月、大还丹顶 3 个月，按抗药性折算。

```
【以丹养伤】你用生肌丹为苏瑶疗伤，调养时间缩短约 2 个月，已然痊愈。
```

## 遗留

- **炼丹还没做**：地火、丹方、成丹率、失败出废丹都还没有，目前丹只能买/捡。
- 丹毒（妖丹之毒）没接，只做了抗药性。
- 筑基丹只作为剧情与身价锚点，不参与突破判定。
- 抗药性按"次数"算，不看境界差；跨境界换丹才是原文的正解，现在是"换丹自然就好使"——恰好对得上。
