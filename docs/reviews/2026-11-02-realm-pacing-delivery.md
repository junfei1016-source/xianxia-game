# 第九轮交付：境界推进按小说节奏（v1.7.0）

日期：2026-11-02 ｜ 范围：给大境界加"最少在境年限"

## 问题

之前只要修为攒满、模型写一句突破，境界就往上跳。一场游戏从凡人到化神可能只花十几年——
和小说差了一个数量级。原著里卡境界靠的是**岁月 + 机缘**，不是攒够经验条。

## 依据（都能回原文核）

| 出处 | 原文要点 |
| --- | --- |
| 第 176 章 | "再苦修百余年，就是进入结丹期也不是没可能" |
| 第 459 章 | 乱星海"百余年"才出一个最有希望元婴的结丹 |
| 第 1225、1228 章 | 化神寿元"两千余岁" |
| 第 1862 章 | 韩立"骨龄才刚二千余岁"，修为已至合体/大乘 |

## 做法：修为照涨，但大境界有"岁月门槛"

```
REALM_MIN_YEARS = { 凡人:3, 炼气:8, 筑基:60, 金丹:100,
                    元婴:200, 化神:300, 炼虚:400, 合体:500, 大乘:700 }
```

- 玩家进入某大境界时记 `world.realmSince`；
- 突破时若目标是大境界、且 `yearsInRealm < 下限` → **拒绝**，叙事保留、境界不动，诊断里记 `breakthrough_too_soon`；
- 小境界（初期→中期→后期）不受限，当年可连破；
- 每回合提示词带"你在本境已历约 X 年，还差约 Y 年"；
- 突破成功后重置 `realmSince`，重新计时。

### 为什么不用"调低修为增速"

1. 筑基期 60 年摊到 100 分制，每月约 0.1 分，取整就归零；
2. GM 写"修为 +10"时并不知道这 10 分在筑基期意味着什么，提示词约束不了它。
   用年限门槛，判定在代码里，模型改不动。

## 遗留

- 年限是**硬下限**，天材地宝只能缩短攒修为的时间，不能越限。若要做"逆天机缘可越限"，
  建议另开一次性捷径（每百年一次、消耗珍稀物），不要直接放宽表。
- 一局到渡劫约 2270 游戏年，依赖玩家习惯"闭关数十年"推进；嫌慢只改 `REALM_MIN_YEARS` 一张表。
- 年限表是按原著零散锚点插值的工程取值，不是原文逐境年表。
- 没做"同境界内小境界也要时间"——小境界仍可当年连破，这与原著大体一致（小境界卡的是修为与丹药）。
