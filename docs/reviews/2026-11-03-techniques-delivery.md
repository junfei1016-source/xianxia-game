基础 / 低阶 / 中阶 / 高阶 / 顶阶，各有修为门槛（炼气 → 元婴），倍率 ×1.0~×3.0。

## 三、层次与主修

- 1~9 层，第 N 层要 `N×100` 火候，火候满 + 灵石够就自动破层；
- 主修只吃一门，**转修散掉一成修为**；
- 主修加修炼，炼体减伤，剑诀伤敌，神识助破阵。

## 四、秘密拜师败露

- 记录在 `player.craftSecrets`；
- 每过一月 `2%`，旧师信任 ≥60 则 ×1.5，上限 85%；
- 败露：旧师信任 −40、怨恨 +30、声望 −10，记录清除。
