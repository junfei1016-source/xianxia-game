# 第四十一轮（补丁）：v1.38.1 传闻只从人嘴里来

日期：2026-11-04。从 `a3c0a58`（v1.38.0）继续。用户一句"按小说来，不用机械弹传闻"，全改。

## 改了什么

| 之前（v1.38.0） | 现在（v1.38.1） |
| --- | --- |
| 每三回合定时冒一条传闻 | **没有定时器**。没人问、没挪窝，一条都不会有 |
| 来源随机 | 按场景：荒原野地是樵夫/游方道人/同路散修；坊市城池是茶馆掌柜/药童/驿馆伙计 |
| 真假固定六四开 | 真话概率 = `0.5 + 声望/400 + 境界档×0.1`（上限 0.9）——身份越高，听到的实情越多 |
| — | 新增**主动打听**：模型登记 `askAround`，系统给一条街谈，同地同月只出一次 |
| — | 新增**初到一地**：跨区抵达时落脚处听到一句（原著里先打听再动身） |

`tickRumors` 改名为 `settleRumors`，只做一件小事：让旧的传闻到三回合自己见分晓（应验／是虚的，写进事迹）。

## 接口

```js
askAround(world, player, opts) -> { rumor, note } | null   // 打听；同地同月冷却
settleRumors(world, player)                                // 只结算，不新增
rumorsFor(player, world)                                   // 玩家能看到的几条（元婴以上标"不像实话"）
```

模型侧新增字段 `askAround: { about: "打听什么" }`，两套输出 schema 与字段说明都已同步；提示词明确
"消息由系统给，你只把人话写进叙事，不要自己编消息或结论"。

## 测试

| 检查 | 结果 |
| --- | --- |
| `tests/sky-rumors.test.mjs` | **13/13**（新增三条：不按回合生成、打听才有一条、荒野/坊市说话的人不同） |
| 全量离线 | **45/45 套**通过 |
| 前端冒烟 | 运行时错误 0 |

测试里写死了一条纪律：**过 30 个回合 settleRumors，传闻数必须仍是 0**——防止哪天又有人把定时器加回来。

## 未验证

- 真实模型联调：没跑（要 Key、会计费）。所以"GM 是否会主动登记 `askAround`"只有提示词约束，未经实测。
- 真浏览器渲染：沙箱禁止无头 Edge 起进程，只有 DOM 垫片冒烟。

## 下一步可选

1. 打听要**花灵石**（一块问一条更准的），或要求对方**关系够**才肯说实话——把"问消息"真正接到交易与关系网。
2. 传闻可以带**地名指向**（"听说北边某处出了异象"），玩家循着去才有事，与秘境/采集点挂钩。
