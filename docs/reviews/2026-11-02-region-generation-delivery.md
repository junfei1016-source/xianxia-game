# 第二十轮交付：玩家开新域的生成标准（v1.18.0）

日期：2026-11-02 ｜ 范围：让"玩家发现一片新地界"有规则可依

## 问题

地图补到九域之后，玩家必然会在叙事里"发现一片秘境""打通一条 ancient 路"。
如果不给标准，模型会顺手开出一块灵气九、危险零、满地神品的宝地——
地图做得再好，也会被一次"发现"抹平。

## 做法：标准 + 校验 + 存档

模型只能**提议** `newRegion`，入图由代码判定：

```
名字 2~8 字且不重名
地形 2~8 字
灵气 1~6 整数 · 危险 1~5 整数
至少一条 1~60 日的通路（必须指向已存在区域）
描述 ≤90 字
产出上限 = floor((灵气+危险)/2)
仙品要灵气或危险 ≥4 · 神品要灵气 ≥5
一局最多 24 块新域
```

合格的存进 `world.dynamicRegions`，**返程路程自动补齐**（双向对称），
`travelTo`、世界切片、物价系数都立刻认它。

不合格的：整条丢弃、记 `region_invalid` 并给出具体原因，世界不留半块脏数据。

## 为什么产值要这样卡

九域的规律是"地气决定产出"：青芜（2/1）只出灵品，大衍（3/3）出玄品，
寒渊（3/5）才出仙品，太清（6/3）才有神品。
所以新域的产出必须跟着 `(灵气+危险)` 走，不能"又安全又出仙材"。

## 遗留

- 新域不能自带**势力与地标**：现在只有一块地，没有本地宗门、坊市、秘境；
- 新域还没接**拍卖排期**（等拍卖改成按区域随机后再接）；
- 没有"区域演化"：新域不会随大势变危险、衰竭或繁荣；
- 24 块上限是硬编码的工程值，若要按境界解锁（如元婴以上才开得出新域），可再加门槛。
