# 第四轮交付：人物性格多元化（v1.3.0）

日期：2026-11-02 ｜ 范围：把 NPC 性格从"自由发挥"改成"有坐标的库 + 反重复"

## 问题

之前的性格是自由文本，提示词里只举了五个例子：傲娇、伪君子、面冷心热、豪爽、阴狠。
模型于是把满世界都写成同一种人——清冷寡言、话少、眼神复杂。玩家见十个人，像见一个人。

## 做法：六轴坐标 + 44 个特质 + 反重复

### 1. 六轴

温度（热络↔疏冷）、城府（深沉↔直白）、守序（守矩↔随性）、义利（重义↔重利）、
胆气（勇决↔谨慎）、情绪（外烈↔内敛）。每个特质是六轴上的一个点，天然分成不同象限。

### 2. 44 个特质

每个特质带 `gist`（一句话设定）与 `speech`（说话习惯）。例如：

| 特质 | 一句话 | 口吻 |
| --- | --- | --- |
| 笑面虎 | 见面三分笑，算计在心底 | 句句客气，从不把真意说满 |
| 闷葫芦 | 三棍子打不出一个屁，心里门儿清 | 多数时候点头摇头，急了才蹦几个字 |
| 算盘精 | 凡事算三遍，连人情也记在账上 | 说话前先顿一下，爱说"这账不对" |
| 铁石心肠 | 该杀就杀，眼里没有"可怜"二字 | 只问结果，不接话头 |
| 刀子嘴豆腐心 | 嘴上不饶人，真到事上护得最紧 | 话尾带刺，转身却把事办了 |

分布（每轴两极人数，44 人）：温度 20/10、城府 14/13、守序 15/15、义利 19/13、胆气 23/11、情绪 16/19。
**这张分布本身就由测试守着**（每极至少 6 人），免得以后加特质又全往"热络勇决"堆。

### 3. 生成契约

`newNpcs` 现在要求：`temperament`（外显气质）、`personality`（真实性格）、`trait`（库内标签）、
`desire`（想要什么）、`taboo`（碰不得什么）、`speech`（说话习惯）。
欲望与忌讳不是装饰——它们是玩家可以借力的软肋与逆鳞，决定此人为何帮你、又为何翻脸。

提示词同时禁用默认写法："不要默认清冷寡言或傲娇"；相邻 NPC 至少两条轴一正一反。

### 4. 反重复（代码层）

- `world.traitLog` 记录最近 20 位登场者的坐标；每回合把**最近 6 位点名**给模型。
- `axisProfile` 统计这 6 位的六轴均值；某一极**连续 3 人以上**就生成警告："最近偏「疏冷」的人太多，本轮请换一种。"
- 轮换建议从"最近 8 位没用过"的特质里取 3 个；`traitCursor` 只读推进，保证 44 个会轮完，且同一回合多次拼提示词得到同一份建议（不破坏前缀缓存）。

实际注入效果：

```
【人物差异化】最近登场：柳三娘（笑面虎）、顾青梧（刀子嘴豆腐心）。本轮若再引入新人物，
别与这几位同轴同调，优先选：守财奴、痴人、落拓狂生；每人补一句欲望、一句忌讳、一个说话习惯。
```

## 遗留

- 特质库是手写的，44 个够用但不算穷尽；若要再扩，加在数组里即可，测试会自动检查分布。
- `desire/taboo` 目前只存不用：还没接"玩家踩到忌讳会怎样"的判定。这是下一步最值得做的（逆鳞机制）。
- 模型可能仍给库外描述（如"说不清的自在"），系统会原样保留为自由文本，不进坐标统计。
- 没有做"同一宗门内性格撞车"的检查——目前只按最近登场顺序去重。
