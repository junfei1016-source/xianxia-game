# 第七轮交付：别人也有各自的关系网（v1.5.0）

日期：2026-11-02 ｜ 范围：NPC 与 NPC 之间的关系边

## 问题

到上一轮为止，所有关系都是**以玩家为圆心**的：`world.npcs` 是一圈点，每个点只有一条连到玩家的线。
NPC 彼此之间是断开的——苏瑶和顾长歌是不是同门、柳三娘认不认识血刀寨的人，系统不知道，
GM 只能每回合现编，编完就忘。

## 做法：`world.npcLinks`

```
{ a: '苏瑶', b: '顾长歌', type: '师承', note: '同门师兄妹', turn: 12 }
```

八种边：**师承 / 同门 / 亲属 / 道侣 / 结义 / 主仆 / 仇怨 / 交易**。

### 怎么产生

1. **显式声明**：`newNpcs` 每项可带 `links: [{to, type, note}]`，`to` 可以是同批新人、也可以是已有的人，甚至是"老樵夫"这种旧称（走 `aliasMap` 解析）。
2. **血缘自动**：`family: {of, relation}` 已经在用的字段，现在会自动补一条 `亲属` 边，不用写两遍。
3. **去重**：同一对人物 + 同一类型只留一条；边数上限 60（保留最近的）。

### 怎么用

- 每回合提示词里带一段【人物关系网】（最近 8 条），并明确要求：
  > 这些人之间的亲疏恩怨会影响他们的言行与站队（帮亲、护短、迁怒、通风报信），不得改写已登记的关系。

- **牵一发动全身**：新人入场时，初始态度受关系网影响——其结义兄弟若与你结仇（怨 ≥60），
  他一上来 `trust −10 / grudge +20`；其同门若信得过你（信 ≥70），他先 `trust +10`。
  这条是自动的，不需要模型记得。

### 示例

```
【人物关系网】苏瑶—顾长歌（师承：同门师兄妹）；柳三娘—王铁山（交易：老主顾）；王铁山—血刀寨（仇怨：夺货之恨）
```

## 遗留

- 边目前是**静态**的：只在生成时建立，还没有"关系随时间变化"（结拜变仇敌、师徒反目）。
- 仇怨/盟友还没有扩散到**势力层**：NPC 的师门如果是敌对势力，目前不会自动敌对。
- 关系网没有"可视化"：只在提示词和图鉴 tooltip 里，没有关系图面板。
- 边没有权重：只知道"有仇"，不知道"仇多深"（深度在四维账本里，但账本记的是玩家与他的，不是他与别人的）。
