# 第十七轮交付：黑市与拍卖会（v1.15.0）

日期：2026-11-02 ｜ 范围：禁制之物的流通渠道 + 竞价场景

## 补的是什么

上一轮交易只有"正经坊市"一种渠道：有钱就能买，禁制丹也一视同仁。
但《凡人修仙传》里，**禁制之物是买不到的**——正经坊市不敢卖，只有黑市敢，而且买它要折损道心。
另一头，**拍卖会**是原著出现最频繁的场面（联合大拍、晋京拍卖会、一明一暗两场），
不该只是一句叙事。

## 黑市

| 规则 | 实现 |
| --- | --- |
| 地点 | 危险度 ≥4 的无法之地（赤沙荒原） |
| 货 | 禁制类丹药与丹方（蚀骨丹、血煞丹、血煞丹方） |
| 正经坊市 | 直接拒绝："禁制之物，正经坊市不敢卖——去黑市碰碰运气" |
| 代价 | 每笔 **正邪 −3** |

## 拍卖会

只在落霞坊；`auctionBids: [{item, bid}]`：

```
起拍价 = 市价 × 1.5
对手出价 = 起拍价 × (0.85 ~ 1.35) 随机
出价 > 对手 → 落槌、扣钱、入库
出价 ≤ 对手 → 没拍到，灵石一分不动
低于起拍价 → 直接拒
```

"举牌不是付款"——输家不扣钱，这是和普通购买最大的区别。

## 数值观察

禁制丹方在黑市的实际价格 = 丹价 2000 × 来源 4 × 3 × 黑市 2 = **48000 灵石**。
这个价不是随便定的：它意味着"想炼禁制丹，先得攒半辈子"——与原文"魔道禁丹不是散修玩得起"一致。

## 遗留

- 拍卖会没有"场次"概念：不按日期开，玩家随时能举牌（下一步可以接到区域活动的排期上）。
- 拍卖对手是"隐形的一手"，没有具体 NPC，也没有"跟人结仇"的后果。
- 黑市只有价格与正邪代价，没有"被正道盘查"的风险。
- 禁制丹的"损德"仍只在购买时扣正邪，服用时不扣。
