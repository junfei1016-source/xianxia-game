# 第五轮交付：势力底细要等玩家查出来（v1.3.2）

日期：2026-11-02 ｜ 范围：把"表里不一"从开局标签改成可调查的暗线

## 问题

上一版世界切片里，白鹿观一开局就带 `·表里不一`。这是给 GM 的提示，但等于把谜底直接写在题面上：
GM 知道了，就容易在措辞里漏出来；玩家一开局就看到"这家有问题"，探索的乐趣就没了。

## 做法：真相与线索分离，分三段放行

| 阶段 | 引擎知道 | GM 知道 | 切片显示 |
| --- | --- | --- | --- |
| 未起疑 | 全部真相 | 什么都不知道 | 白鹿观（三级·中立） |
| 已起疑 `hinted` | 全部真相 | 真相 + 可给的线索，且被要求"不得点破" | 白鹿观（三级·中立·有蹊跷） |
| 已查明 `revealed` | 全部真相 | 可以正常引用 | 白鹿观（三级·中立·表里不一）＋【已查明】真相 |

### 1. 起疑的触发

玩家输入里有调查类动词，并且点到了某家势力名，才算起疑：

```
/打听|查探|探查|追查|追问|求证|暗访|走访|盘问|试探|跟踪|盯梢|查一查|查查|调查|问起|翻查|摸清|摸一摸|套话|留意/
```

`noteInvestigation(world, text)` 在每回合开头调用，命中就把 `world.knownSecrets[势力id] = 'hinted'`。
只提名字（"白鹿观最近香火不错"）不算，防止 GM 顺手把线索倒出来。

### 2. 起疑后交给 GM 的东西

```
【暗线·玩家正在查】玩家已起疑。本轮只能给互相矛盾的细节与可查的线索，不得直接点破，
也不得让玩家凭空确认；玩家查到实证后，用 reveals 登记 [{faction:"势力名"}]。
- 白鹿观：真相是「白鹿观明面中立，实为血刀寨暗桩，替其销赃、递消息。」；
  可给的线索：夜里常有戴斗笠的人从后门进出；账上多出一笔来路不明的灵石，记作"香火"。
```

真相给了 GM，但口径锁死：**只能给线索，不能给结论**。

### 3. 查明的门槛

提取器新增 `reveals: [{faction}]`。系统只接受**已经起疑**的势力——没调查过就报"查明"直接丢弃，
防止模型顺着想象编出"你查明了白鹿观的底细"。

查明后：
- `knownSecrets[id] = 'revealed'`；
- 记一笔事迹「查出底细」；
- 这家势力进入玩家名单（图鉴里打"底细已明"）；
- 切片追加【已查明】真相，GM 之后可以正常引用。

### 4. 本轮两条底细

| 势力 | 真相 | 可给线索 |
| --- | --- | --- |
| 白鹿观 | 明面中立，实为血刀寨暗桩，替其销赃、递消息 | 夜里戴斗笠的人走后门；账上多出一笔"香火" |
| 青芜王朝 | 年年向拾云门纳贡，换修士护国 | 秋后国库少一笔银子，记账"河工"，可河工从没修过 |

## 遗留

- 起疑靠关键词，玩家用"我想知道白鹿观背后是谁"这种绕法可能不触发；可以把动词表再放松，或者让 GM 在 `reveals` 前先补一次 `hints`。
- 只做了两条底细，且与具体区域绑定；换新区域要补表。
- 查明后没有"揭穿"的后果（血刀寨翻脸、白鹿观报复），目前只到"知道"为止。
- 图鉴只显示"底细已明"，不展开真相；真相只在叙事与事迹里。
