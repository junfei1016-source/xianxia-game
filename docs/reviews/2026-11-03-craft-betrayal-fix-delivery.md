# 第三十三轮交付：叛门改为"投敌师"才触发，顿悟转为引擎自发（v1.31.0）

日期：2026-11-03 ｜ 范围：修正上一轮叛门规则（用户指出不对）+ 补引擎自发顿悟

## 一、问题

上一轮写成"同一门技艺另投他师即叛门"，这是错的，理由有三（用户指出）：

1. 只有**投到与师门为敌的人**门下才算欺师灭祖；
2. 小说里**前期师父到后期本就没有交集**（墨大夫与韩立晚年），再拜师不该受限；
3. **秘密拜师**只要旧师不知道，就不该触发。

## 二、改法

叛门须**三条同时成立**：

| 条件 | 判定 |
| --- | --- |
| 新师与旧师为敌 | NPC 间有「仇怨/敌对/世仇」连线，或两家势力在关系表里敌对/世仇 |
| 旧师仍把你当徒弟 | NPC 关系含师父/拜师/师徒，且信任 ≥20 |
| 你没瞒着 | `secret` 未置 true |

- 满足：旧师信任 −40、怨恨 +30、声望 −10；
- 不满足（无仇）：回执写"旧师「X」与你已无甚交集，另投 Y 不算背师"；
- **秘密拜师**：`secret: true` 不触发，但在 `player.craftSecrets[技能]` 记下旧师、新师、月份，日后可被揭破。

## 三、顿悟改为引擎自发

- 卡瓶颈后，每次 `practiceCraft` 引擎掷一次：`6% + 卡关次数×3%`，上限 35%；
- 悟开：直接进下一级，回执"忽然心头一亮——那层窗户纸破了"；
- 没悟开：回执"仍是不得其门（卡在瓶颈第 N 回）"；
- 手动 `craftInsight` 仍保留，供 GM 叙事直接给顿悟。

## 六、教训

"叛门"是**关系判定**，不是**动作判定**：同一动作（换师）在不同关系下性质完全不同。
写规则时先问"谁知道、谁在意、跟谁有仇"，再决定是否扣分。

## 七、遗留

- 叛门没有后续追杀或门派通缉；
- 秘密拜师只记在册，没有"被揭破"的引擎判定；
- 势力敌对判定依赖 `npcLinks` 连线或 `world.js` 关系表，NPC 若无门派信息则不触发（设计上从宽）。
