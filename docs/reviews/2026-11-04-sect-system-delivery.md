## 一句话

以前只有"势力"没有"宗门"：你能跟它做买卖、接它的活、跟它结盟，但**你不能是它的人**。这轮补上：入门 → 外门/内门/亲传/执事 → 攒贡献 → 进藏经阁换本门东西 → 好聚好散或携艺叛门。

## 规则

1. **入门** `joinSect`：须在该势力地界、非敌对、炼气以上；一个身子只能进一家。
2. **辈分** `SECT_RANKS`：外门（0 贡献）→ 内门（30 + 炼气中期）→ 亲传（120 + 筑基初期）→ 执事（400 + 金丹初期）。每年结算时自动判一次，够条件就晋阶。
3. **贡献**：只认**本门**的差事（`addSectContribution` 校验 factionId === sect.id）。
4. **藏经阁** `sectRedeem`：外门弟子进不去；货按门派立场分三套（正道/魔道/中立）；扣贡献、记 `sect.bought`。
5. **离门** `leaveSect(betray=false)`：好感 −20、贡献清零、好聚好散。
6. **叛门** `leaveSect(betray=true)`：门派转敌对、好感 −100、`flags.sectTraitor = true`，回执会写明"带着抄走的几样东西"。
