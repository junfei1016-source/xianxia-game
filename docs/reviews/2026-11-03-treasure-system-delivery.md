# 第二十一轮交付：法宝按小说重写（v1.19.0）

日期：2026-11-03 ｜ 范围：法宝从"通用装备"改为有阶位、有驱动门槛、有本命祭炼

## 问题

旧法宝体系只有 `grade`（基础/玄阶/地阶/天阶/仙阶）+ `rarity`（凡品～神品）两轴，
完全靠模型自报，既没有小说里的**法器→法宝→古宝→灵宝→通天灵宝→玄天之宝**层级，
也没有"修为不够驱动不了"和"本命法宝"这两条最像原著的规则。

## 做法

新增 `public/treasures.js`：

1. **九阶表**：法器 / 下品·中品·上品·极品法宝 / 古宝 / 灵宝 / 通天灵宝 / 玄天之宝，
   每阶带 `minRealm`、威力、破境加成、价目、能否流通。
2. **二十件名录**：青叶飞剑、铁精盾、金砖、定风珠、天雷竹、金蚨子母刃、元磁神山、
   青竹蜂云剑、七焰扇、寒髓镜、紫铖兜（古宝）、虚天鼎（通天灵宝）、玄天斩灵剑、掌天瓶（玄天之宝）……
3. **驱动门槛**：差一个大境界发挥五成，差两个以上完全无效。
4. **本命法宝**：`refineTreasure`，金丹以上、唯一、耗三成气血+灵石、威力 ×1.25。
5. **不流通**：古宝以上 `itemPrice` 返回 null，买卖直接拒。

## 顺手修的一个旧漏洞

旧 `isFunctionalTreasure` 会把"只有功能词条、没有修炼词条"的法宝判为**常驻免费法宝**——
于是元磁神山、青竹蜂云剑这类上品法宝，不占槽、不用装备也能生效。
新规则：名录法宝（有 `tier`）一律走阶位与槽位，不再享受常驻待遇。

写测试时踩了两个坑：

1. 跨境界比"修炼收益"是错的——筑基与金丹的月增速本来就不同，必须同境界对比；
2. 青竹蜂云剑带「悟道」词条，会把 1.4 倍冲成 1.54 倍，测阶位倍率要换一把没有修炼词条的法宝（金蚨子母刃）。

## 遗留

- **没有炼器**：丹药有炼丹炉，法宝还没有"以材料炼器"的流程；
- 无毁损、无自爆、无夺宝；
- 器灵只写在描述里，没有机制（可做"灵宝以上自动护主一次"）；
- 名录外法宝仍由模型命名、自报品阶，越级校验还没做。
