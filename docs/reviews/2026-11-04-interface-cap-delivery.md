## 规则

1. **人界上限 = 化神后期**。`realmCapFor(world)` 按当前所在地的界面返回上限：人界返回 `化神后期`，灵界返回 null。
2. **越阶被挡**：`applyStateUpdates` 处理 `realmChange` 时先查界面上限，超出则记 `interface_cap` 并丢弃该条（叙事保留、境界不动）。
3. **破界飞升灵界**：`canAscendToSpirit(player, world)` = 人界 + 化神后期 + 修为 100。满足时 `travelTo` 指向灵界任一地界，就直接落到**飞灵台**（日数 0，不是走过去的），并给出破界回执；不满足则回执"界力所隔"。
4. **下不去**：已在灵界时，任何指向凡界的 `travelTo` 都回执"界力所隔：到了灵界，便下不去人界了"。
5. **灵界无上限**：炼虚→合体→大乘→渡劫照旧可升；`飞升` 只在灵界达成，触发通关结局（飞升仙界）。

## 接口

```js
MORTAL_CAP = '化神后期'
interfaceOf(world) -> '人界' | '灵界'
realmCapFor(world) -> '化神后期' | null
canAscendToSpirit(player, world) -> boolean
```

诊断码新增 `interface_cap`：`人界只到化神后期，炼虚以上须飞升灵界才修得。`

## 测试守住的关键几条

- 人界：化神中期→化神后期放行；化神后期→炼虚初期被 `interface_cap` 拦下且境界不动。
- 灵界：炼虚→合体→大乘→渡劫四段全部放行。
- 灵界：渡劫后期→飞升，`evaluateEndings` 给出 `ascend`（win=true）。
- 破界：修为不足或境界不够，人还在人界，回执里点明"界力"。
- 破界成功：落在 `feiling`，`interfaceOf` 立刻变灵界、无上限。
- 灵界内部可互相走动，但回人界的路被封死。
