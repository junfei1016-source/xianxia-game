## 做法

### 1. 四艺造诣

符箓 / 阵法 / 丹道 / 炼器，五级：未入门 → 初窥门径 → 略有小成 → 登堂入室 → 炉火纯青 → 出神入化（每 100 经验一级）。

**两条提升路**：

- 自练 `practiceCraft`：花时间，等级越高越慢（`天数×3 ÷ (1+等级×0.35)`）；
- 求教 `studyCraft`：师父（师徒名分 + 信≥60，+60 经验）或玉简（读一次 +40）。

### 2. 造诣的实际用处

| 技艺 | 加成 |
| --- | --- |
| 丹道 | 成丹率 +2%/级 |
| 炼器 | 成器率 +2%/级 |
| 阵法 | 破阵率 +3%/级、布阵 −5%/级 |
| 符箓 | 成符率 +3%/级、符威 +10%/级 |

### 3. 符箓

十种符（疗伤/金刚/神行/火球/剑符/雷符/回春/遁地/封灵/仙符·太清），四阶（凡/灵/宝/仙），画符要符纸朱砂、高阶加灵墨妖血；用掉即废，护身符力限时 1~3 个月。

### 4. 珍材代地脉

灵气 <3 的地方布大阵，可用**三份灵品以上材料**代地脉。

## 踩到的坑

把符力增益写成 `buffFx`，但行路结算在它声明之前执行——`ReferenceError: Cannot access 'buffFx' before initialization`，
两个行路用例当场红。改成在行路处就地取 `travelBuff`，问题消失。**JS 的 TDZ 不会因为你写的是"配置"就放过你。**

## 遗留

- 四艺没有瓶颈与顿悟；
- 符箓不能多张叠加、没有"符阵"；
- 造诣没有师承上限（叛门、换师都还没做）。
