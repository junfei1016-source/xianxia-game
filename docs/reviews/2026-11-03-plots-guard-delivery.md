# 第二十八轮交付：守护缠斗与灵田经营（v1.26.0）

日期：2026-11-03 ｜ 范围：守护从"一次判定"变成多回合；采集点从"只能等"变成"可以养"

## 一、守护改成多回合缠斗

| 项 | 规则 |
| --- | --- |
| 耐久 | 玄品 8、仙品 9、神品 10 点 |
| 每合伤害 | 1 + 境界高一档 +1 + 带攻击型法宝 +1 |
| 回合上限 | 六合，或玩家气血跌破两成自动退 |
| 打赢 | 守护倒下，这处不再拦你 |
| 打输 | 受伤撤退，**守护记仇半年**；耐久接着算，下次来是残血状态 |

- 同境硬拼（伤害 1）六合只能打掉 6 点，**打不完 8 点耐久的玄品守护**——这就是"境界不够别硬碰"；
- 高一档（伤害 2）+ 攻击法宝（伤害 3）才有胜算：元婴带青竹蜂云剑，三合内可下仙品守护。

记仇期间再靠近：

```
【采集】矿脉（仙品）旁，护脉石傀还在气头上，你暂且绕开。
```

——不再重复挨打，但也不给捡漏。

## 二、灵田/矿脉经营

`plant { material }` → `tendPlot { id }` → `harvestPlot { id }`

- **最多三处**，耗一份作种，且必须是**当地养得活**的材料（青芜养不活陨铁）；
- 成熟周期沿用采集点年数：凡品 2 年 → 神品 800 年；
- **照料**：耗灵石（阶位价的一成），成熟提前约两成；
- **收成**：凡/灵/玄 两份，仙/神 一份；收完这块田就空了，要重新种。

这补上了"长期投入"：种一株千年血参，得真等一千年，或者不停投灵石照料。

## 五、踩到的坑

第一版守护耐久只有 `2 + rank`（5 点），结果**同境玩家六合也能打完**——"境界不够别硬碰"根本没成立。
把耐久提到 `6 + rank` 后，同境伤害 1 只能打 6 点、打不完 8 点，规则才真的咬合。
写测试时先被这条反咬：低境界用例里守护反而被打死了。

## 六、遗留

- 守护没有"技能/属性"，只是耐久与伤害的数字；
- 记仇只在同一处采集点，不会追到别处；
- 灵田没有"地块品质/阵法加成"，照料也只是按比例提前；
- 收成没有"变异/品相"（小说里常有一株灵药药性超出年份）。
