# 第二十七轮交付：采集点的长周期、守护与大势浮动（v1.25.0）

日期：2026-11-03 ｜ 范围：按小说时间线拉长刷新、给高阶点配守护、稀有度随大势变

## 一、刷新按小说年数

| 稀有度 | 旧（月） | 新（年） | 新的月数 |
| --- | --- | --- | --- |
| 凡品 | 6 | 2 年 | 24 |
| 灵品 | 12 | 10 年 | 120 |
| 玄品 | 24 | 50 年 | 600 |
| 仙品 | 48 | 200 年 | 2400 |
| 神品 | 96 | 800 年 | 9600 |

依据是小说里"百年灵草、千年血参、万年灵乳"的年份口径：**灵药不是半年就能再长一茬的**。
玩家一局动辄两三千年，200 年的仙品点相当于"一生只遇一两次"。

## 二、高阶采集点有守护

- **仙品以上必有守护**，玄品三成概率；
- 守护是守药妖兽 / 护脉石傀 / 毒蛟 / 铁背妖狼 / 阴魂，境界按稀有度：玄品≈金丹、仙品≈元婴、神品≈化神；
- 采之前先过一关：`成功率 = 0.5 + (你的大境界 − 守护境界) × 0.15`，夹在 5%~95%；
- 打不过：**采不到，还伤 20%~40% 气血**，采集点不被消耗；
- 打赢：守护倒下（这处不再拦你），照常采。

## 三、稀有度随大势浮动

| 大势 | 稀有度上限 |
| --- | --- |
| 秘境将启 | **+2 档** |
| 盛世 | +1 档 |
| 乱世 | 不变 |
| 正魔大战 | −1 档 |
| 末法时代 | **−2 档** |

例：青芜平时只出凡品，秘境将启时能催出灵品；末法时代连星陨荒原都不再出仙品（退而取本地最低阶的玄品）。

## 四、恢复时重掷

采集点到期恢复时，按**当时的大势**重新生成材料与守护——
"灵气环境变了，长出来的东西也变了"，而不是按生成时的旧档位复活。

## 六、测试日志

```
[离线测试] 采集点守护与大势
ℹ tests 7  ℹ pass 7  ℹ fail 0
[离线测试] 采集点稀有度
ℹ tests 8  ℹ pass 8  ℹ fail 0
离线测试完成：34/34 套通过
```

写测试时发现一个**旧用例的假通过**：上一轮"隔几个月恢复"其实只采空了一处，
第二次采到的是另一个新鲜采集点，根本没测到"恢复"。这轮改成三处全采空、再等三年，才是真恢复。

还有一个实现漏洞：大势压到低于当地最低材料时（末法 + 星陨），`fillNode` 会退化成"取池子第一个"，
可能取到仙品。已改为**取本地最低阶的那一种**。

## 七、遗留

- 守护只是"一次判定"，没有连续战斗、没有仇恨与追杀；
- 大势切换频率由提取器给（`eraChange`），采集点不会主动提示"灵气变了"；
- 没有"灵田/矿脉经营"：采空只能等，不能养。
