# 第五十一轮交付：v1.48.0 天渊城服役

日期：2026-11-04。分支 `codex/state-input-guards`，从 `4d6691e`（v1.47.0）继续。只做本地提交。

## 一句话

灵界终于有了第一个真正的玩法循环：**在天渊城入伍当青冥卫，每年领一粒灭尘丹，服够三百年满役自由**。黑户想走这条路，得先办身份牌洗白。

## 规则

1. **入伍** `enlist`：须在**天渊城**、**有仙籍**（`spiritOutlaw` 为假）、**未在册**、未满役。回执："名字录进青冥卫名册"。
2. **年度结算** `settleDuty`（随 `advanceTime`）：
   - 每年发一粒灭尘丹并服下 → `outlaw.unsuppressedMonths = 0`；
   - 差事四分枝：巡边（+1 军功）／守城（无事）／妖族袭扰（气血 −8%，+2 军功）／截货（+3 军功、+300 灵石）；
   - 满 `DUTY_YEARS = 300` 年 → `flags.spiritFree = true`、rank 改"已退役"。
3. **黑户被挡**：`canEnlist` 直接回"无籍者进不了天渊城名册，先办身份牌洗白"。
4. 模型侧新增 `enlist: {}` 字段（两套 schema + 提示词）。

## 界面

状态面板在灵界多一行：

```
服役  青冥卫 · 第 37 年 / 300 年 · 军功 52
```

满役后变成"已满役（可自由离开天渊城）"。

## 本轮踩的坑

- 一开始按用户说的"服役百年"去写，查原著发现是**服够三百年**（第 1316 章），照原文改了，并加了一条测试把"服役 300 年 === 两色雷劫 300 年"钉死，防止以后又被改成别的数。

## 未做

- 军功还没有**兑换处**（换丹药、法宝、减役？原文里天渊城是有功勋体系的）。
- 服役期间的**妖袭、城防事件**只有一句播报，没有真正接入战斗结算。
- 满役之后"自由离开天渊城"目前只是解除服役，灵界其他玩法（黑市、宗门、跨界传送）还没接。
